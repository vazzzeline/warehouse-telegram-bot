# WMS-Lite Bot — Автоматизация складского учёта

Telegram-бот для оперативного учёта складских операций (приёмка, отгрузка, инвентаризация), интегрированный с интерактивным аналитическим веб-дашбордом на базе **Dash / Plotly**.

## Цели и возможности проекта
- **Мобильный ввод операций:** регистрация приёмки, отгрузки и инвентаризации со смартфона без привязки к стационарному ПК.
- **Единое хранилище данных:** автоматическая запись транзакций в реестр `warehouse_data.csv`.
- **Оперативная аналитика:** генерация экспресс-графиков прибыли по категориям прямо в Telegram и синхронизация с веб-дашбордом Dash (`http://127.0.0`).

## Установка и запуск на локальной машине

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd warehouse-telegram-bot
   ```

2. Установите необходимые зависимости:
   ```bash
   pip install pyTelegramBotAPI pandas matplotlib dash plotly
   ```

3. Укажите токен вашего бота (полученный у `@BotFather`) в переменной `TOKEN` файла `bot.py`.

4. Запустите Telegram-бот:
   ```bash
   python bot.py
   ```

5. *(Опционально)* Для просмотра расширенного интерактивного дашборда запустите веб-приложение в соседнем терминале:
   ```bash
   python app.py
   ```

## Руководство пользователя
- `/start` — запуск бота и открытие главного меню.
- **📥 Приёмка / 📤 Отгрузка / 📋 Инвентаризация** — пошаговая фиксация складской операции (выбор категории → ввод количества, выручки и расходов через пробел).
- **📊 Дашборд и аналитика** — расчёт суммарных KPI склада (выручка, расходы, прибыль), построение диаграммы по категориям и получение ссылки на веб-дашборд.
