# WAREFLOW — Система автоматизации складского учёта (Чат-бот + Веб-приложение + Дашборд)

Комплексное программное решение для оптимизации складских бизнес-процессов (приёмка, адресное хранение, сборка, отгрузка и инвентаризация ТМЦ).

## Архитектура проекта (3 независимых модуля)
Все модули работают с единым хранилищем транзакций `warehouse_data.csv`:
1. **`bot.py` (Telegram-бот `WMS-Lite Bot`)** — лёгкий мобильный интерфейс для кладовщиков: быстрый ввод операций со смартфона в зоне хранения и генерация экспресс-графиков в чат.
2. **`wareflow_web.py` (Веб-приложение `WAREFLOW`, порт `8051`)** — единое рабочее пространство, реализованное по UX/UI-макету из Figma. Объединяет 6 интерактивных вкладок (*Главная*, *Приёмка*, *Адреса*, *Сборка*, *Отгрузка*, *Учёт*), автообновление данных от бота и ссылки на все модули системы.
3. **`app.py` (Аналитический дашборд Dash, порт `8050`)** — панель бизнес-аналитики для руководителя склада с фильтрацией и графиками финансовых показателей.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd warehouse-telegram-bot
   ```

2. Установите зависимости:
   ```bash
   py -m pip install pyTelegramBotAPI pandas matplotlib dash plotly
   ```

3. Запустите модули (в отдельных терминалах):
   ```bash
   python bot.py           # Запуск Telegram-бота
   python app.py           # Запуск отдельного дашборда (http://127.0.0)
   python wareflow_web.py  # Запуск единого веб-приложения (http://127.0.0)
   ```
